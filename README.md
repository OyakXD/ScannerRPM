# ScannerRPM
Scanner automotivo desenvolvido com ESP32 e BeagleBone Black, utilizando o protocolo CAN Bus para transmissão e monitoramento de dados de rotação do motor (RPM).  O sistema utiliza SocketCAN e aplicações em C no Linux embarcado para receber, processar e disponibilizar os dados por meio de uma interface web desenvolvida com HTML, CSS e JavaScript
